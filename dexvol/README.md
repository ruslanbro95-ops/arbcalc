# DEX Volume Anomaly Monitor

Фоновый сервис: следит за торговым объёмом выбранных токенов на DEX, считает
поминутный объём в USD, сравнивает его с медианами за 10m / 30m / 60m / 24h и
шлёт лаконичный алерт в приватный Telegram-бот при превышении порога.

Go, без внешних зависимостей. Нужен только компилятор Go 1.24+.

### 1. Приватный бот

Бот — это одновременно и канал алертов, и панель управления, поэтому доступ к
нему строго один.

1. В Telegram открой **@BotFather** → `/newbot` → получишь токен вида
   `123456789:AAH...`.
2. У **@userinfobot** узнай свой числовой `id`.
3. В настройках бота у @BotFather: `/setjoingroups` → **Disable** (чтобы бота
   нельзя было добавить в группу).

Сервис **не запустится**, если `TELEGRAM_OWNER_ID` не задан. Любое сообщение не
от владельца отбрасывается молча, без ответа: ответ подтвердил бы постороннему,
что бот существует и живой.

### 2. Переменные окружения

```bash
export TELEGRAM_BOT_TOKEN="123456789:AAH..."   # обязательно
export TELEGRAM_OWNER_ID="123456789"           # обязательно, только твой id

# необязательные — у всех есть рабочие значения по умолчанию
export POLL_INTERVAL=12s          # целевой интервал опроса (ТЗ: 10–15 с)

# свои RPC — если публичные упрутся в лимиты
export RPC_ETHEREUM=...

export RPC_BASE=...
```

### 3. Запуск

```bash
./monitor
```

Дальше всё в боте:

```
/add base 0x1111... ABC     добавить токен
/add solana So111...        символ подтянется сам из pool discovery
/list                       что отслеживается
/threshold 30               порог срабатывания, %
/cooldown 10                анти-спам, минут
/escalation 2               во сколько раз аномалия должна усилиться,
                            чтобы пробить cooldown
/windows 24h off            отключить одно из окон
/on  /off                   алерты вкл/выкл (сбор данных продолжается)
/settings                   текущая конфигурация
/status                     ingestion и качество данных
/vol ABC                    объём прямо сейчас
```

Порог и cooldown меняются на лету, без перезапуска и без правки кода. Каждое
изменение сразу пишется на диск, так что переживает рестарт.

## Как это устроено

Главный вывод исследования: **ни один бесплатный источник не закрывает
«5 сетей + поминутный объём + 10–15 с» в одиночку**, зато разные источники
хорошо закрывают разные задачи. Отсюда разделение:

```
        POOL DISCOVERY (раз в 5 мин)
        DexScreener + GeckoTerminal
                    │ список пулов
                    ▼
        TRADE INGESTION (каждые 10–15 с)
        EVM:    eth_getLogs по ВСЕМ пулам сети одним вызовом
        Solana: getSignaturesForAddress + батч getTransaction
                    │
                    ▼
              NORMALIZER  →  DEDUP (chain|tx|log_index)
                    │
                    ▼
              USD PRICING (DexScreener, кэш 10 мин)
                    │
                    ▼
        MINUTE AGGREGATOR → MEDIANS → DETECTOR → COOLDOWN → TELEGRAM
```

Почему именно так, с расчётами по лимитам каждого API — `docs/RESEARCH.md`.
Короткая версия: у EVM один `eth_getLogs` покрывает все пулы всех токенов сети
(**16 запросов/мин на всю систему**), а у GeckoTerminal trades-эндпоинт работает
на один пул при лимите 30 запросов/мин — это **7 пулов** на всё, меньше одного
среднего токена.

### Три решения, которые определяют качество

**1. Пропуск данных — это `MISSING`, а не `0`.**
Минута без сделок при живом источнике — настоящий ноль, она честно опускает
медиану. Минута, которую источник не смог прочитать, исключается из выборки
целиком. Если свалить второе в ноль, все медианы просядут, и первая же
нормальная минута после сбоя прочитается как всплеск. Минута, про которую вообще
никто не отчитался, считается `MISSING` — молчание это отсутствие данных, а не
подтверждённый ноль.

**2. Медиана, а не среднее.**
`[10, 11, 9, 12, 5000]` → среднее ≈ 1008, медиана = 11. Одна крупная сделка не
должна становиться новым «нормальным уровнем», относительно которого меряются
следующие минуты.

**3. Коэффициент эскалации = ×2, а не ×1.5.**
В ТЗ серия +50 / +70 / +80 / +60% описана как **одна продолжающаяся аномалия**,
на которую должно уйти одно сообщение. При ×1.5 минута с +80% пробила бы
cooldown (80/50 = 1.6) и дала второе. При ×2 серия даёт ровно одно сообщение, а
по-настоящему другое событие (скажем, +200%) всё равно проходит сразу — и планка
после этого поднимается до нового уровня.

Всё, что не удалось разобрать, **отбрасывается, а не считается нулём**: лог,
снятый реоргом; сделка без timestamp блока; пул без `token0()/token1()`; сделка
без маршрута к цене; протухшая цена. Это превращается в видимый пробел покрытия
в отчёте — честный режим отказа. Досчитать их нулями значило бы занизить минуту
и утянуть за собой медианы.

## Известные ограничения

**Solana.** Это слабое место, и обойти его бесплатно нельзя. Аналога
`eth_getLogs` нет, а готовый разобранный поток сделок (Helius
`transactionSubscribe`) с апреля 2026 доступен только на платном тарифе.
Реализация читает сигнатуры по каждому пулу и добирает суммы из token-балансов —
это точно, но стоимость запросов растёт с активностью, а не остаётся плоской.
При исчерпании бюджета источник помечает себя нездоровым, и минуты становятся
`MISSING` вместо тихо занижённого объёма.

**Robinhood Chain.** Сеть EVM-совместимая (Arbitrum Orbit, chain ID 4663,
mainnet с 01.07.2026), поэтому работает тем же EVM-адаптером. Но:
GeckoTerminal-идентификатор сети подтвердить не удалось, поэтому вторым
провайдером discovery там выступает только DexScreener. Кнопки GMGN и OKX для
этой сети не выводятся — GMGN её не листит.

**Ссылка OKX.** Шаблон `https://web3.okx.com/token/{chain}/{address}` не удалось
проверить на живой странице. Если он не тот — поправь без пересборки:

```bash
export OKX_URL_TEMPLATE="https://.../{chain}/{address}"
export OKX_URL_TEMPLATE=""     # пустое значение убирает кнопку OKX
```

Шаблон GMGN (`https://gmgn.ai/{sol|eth|base|bsc}/token/{address}`) подтверждён.

**Uniswap V4.** Свопы V4 эмитит `PoolManager`, а не сам пул, — другой формат
события, сейчас не декодируется. Такие пулы попадут в отчёт `cmd/coverage` как
пробел, а не растворятся молча.
